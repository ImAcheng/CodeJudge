# Local Judge
An open source, adjustable code judger for programming practice courses.

## The Story of Local Judge
I started this project in early 2026, I had no idea what should I call this.  
The main judger platform in Taiwan, Zero Judge, gave me some ideas.  
I named this project Local Judge after that.

## Frameworks
* UI - Windows Form Apps (.NET 10)
* API - ASP.NET Web API (.NET 10)

## Includes
* Judger Application
* Problem Designer Application
* API

## Features
* Code Judge provides you with a simple GUI to add your own problems.
* No account requiered.
* Save answering records easily.

## Important
You need to install C/C++ compiler, Java Virtual Machine, or Python interpreter, depending on what you need.  
  
If Visual Studio said *.resx files have problems while building, it's usually caused by network download restrictions.  
Enter the command below in Power Shell in the root folder to solve it:
```ps
Get-ChildItem *.resx -Recurse | Unblock-File
```  

Otherwise, since this project is designed for Taiwanese students, I only make Traditional Chinese version.
